# 什么是 openpilot？

[openpilot](http://github.com/commaai/openpilot) 是一个开源的高级驾驶辅助系统。目前，openpilot 为越来越多的[支持车型、型号和年份](https://github.com/commaai/openpilot/blob/master/docs/CARS.md)提供自适应巡航控制（ACC）、自动车道居中（ALC）、前方碰撞预警（FCW）和车道偏离预警（LDW）功能。此外，在 openpilot 启用期间，基于摄像头的驾驶员监控（DM）功能会提醒分心或瞌睡的驾驶员。了解更多关于[车辆集成](https://github.com/commaai/openpilot/blob/master/docs/INTEGRATION.md)和[局限性](https://github.com/commaai/openpilot/blob/master/docs/LIMITATIONS.md)的信息。

## 如何使用？

openpilot 设计用于 comma four 设备。

## 工作原理？

简而言之，openpilot 利用车辆现有的内置 [ADAS](https://en.wikipedia.org/wiki/Advanced_driver-assistance_system) 系统 API，提供比原厂系统更优秀的加速、制动和转向控制。
