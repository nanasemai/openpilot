# 局限性
## openpilot ALC 和 LDW 的局限性

openpilot ALC 和 openpilot LDW 不会自动驾驶车辆或减少操作车辆所需的注意力。驾驶员必须始终控制方向盘，并随时准备修正 openpilot ALC 的操作。

变道时，openpilot 无法观察您旁边或检查您的盲区。只有在确认安全后，才轻推方向盘以发起变道。

许多因素可能影响 openpilot ALC 和 openpilot LDW 的性能，导致它们无法按预期工作。这些因素包括但不限于：

* 能见度差（大雨、雪、雾等）或可能干扰传感器操作的天气条件。
* 面向道路的摄像头被泥、冰、雪等遮挡、覆盖或损坏。
* 在车辆上使用过多油漆或粘合产品（如贴膜、贴纸、橡胶涂层等）造成的遮挡。
* 设备安装不正确。
* 在急转弯时，如进出匝道、交叉路口等；openpilot 设计为限制其可以产生的转向扭矩。
* 遇到受限车道或施工区域时。
* 在高度倾斜的道路上行驶或遇到强侧风时。
* 极热或极冷的温度。
* 强光（由于对向来车头灯、直射阳光等）。
* 在丘陵、狭窄或蜿蜒的道路上行驶。

上述列表并未穷尽所有可能干扰 openpilot 组件正常运行的情况。驾驶员有责任始终控制车辆。

## openpilot ACC 和 FCW 的局限性

openpilot ACC 和 openpilot FCW 不是允许粗心或分心驾驶的系统。驾驶员仍然需要密切关注车辆周围环境，并随时准备重新控制油门和刹车。

许多因素可能影响 openpilot ACC 和 openpilot FCW 的性能，导致它们无法按预期工作。这些因素包括但不限于：

* 能见度差（大雨、雪、雾等）或可能干扰传感器操作的天气条件。
* 面向道路的摄像头或雷达被泥、冰、雪等遮挡、覆盖或损坏。
* 在车辆上使用过多油漆或粘合产品（如贴膜、贴纸、橡胶涂层等）造成的遮挡。
* 设备安装不正确。
* 接近收费站、桥梁或大型金属板。
* 在有行人、自行车骑行者等的道路上行驶时。
* 遇到交通标志或红绿灯时，openpilot 目前无法检测这些。
* 当发布的速度限制低于用户选择的设定速度时。openpilot 目前无法检测速度限制。
* 同一车道内有静止车辆时。
* 需要紧急制动操作时。openpilot 设计为限制其可以产生的减速度和加速度。
* 周围车辆从相邻车道近距离切入时。
* 在丘陵、狭窄或蜿蜒的道路上行驶。
* 极热或极冷的温度。
* 强光（由于对向来车头灯、直射阳光等）。
* 来自其他产生雷达波的设备的干扰。

上述列表并未穷尽所有可能干扰 openpilot 组件正常运行的情况。驾驶员有责任始终控制车辆。

## openpilot 驾驶员监控（DM）的局限性

openpilot DM 不应被视为驾驶员警觉性的精确测量。

许多因素可能影响 openpilot DM 的性能，导致其无法按预期工作。这些因素包括但不限于：

* 低光照条件，如在夜间或黑暗隧道中行驶。
* 强光（由于对向来车头灯、直射阳光等）。
* 驾驶员面部部分或完全超出驾驶员摄像头的视野范围。
* 驾驶员摄像头被遮挡、覆盖或损坏。

上述列表并未穷尽所有可能干扰 openpilot 组件正常运行的情况。驾驶员不应依赖 openpilot DM 来评估自己的注意力水平。
