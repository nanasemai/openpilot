# 如何提供反馈

作为用户，反馈是为 openpilot 做出贡献的最有效方式之一。

## 驾驶体验

对您的车辆驾驶表现有反馈？
加入社区 Discord，然后使用 `#submit-feedback` 频道中的表单。

提交反馈前，请确保：

- **openpilot 是最新版本** — 您应使用最新的 openpilot 正式版或 nightly 版
- **两个道路摄像头视野清晰** — 挡风玻璃干净，镜头清洁等
- **设备安装正确** — 设备必须水平居中安装在挡风玻璃上且位置较高

## 驾驶员监控

如果您在完全专注的情况下觉得 DM 很烦人，这很可能是误报，我们想要修复这些问题！
一般来说，驾驶员监控反馈非常可行，我们可以在一个发布周期内解决您的投诉。

提交反馈：

1. 加入[社区 Discord](https://discord.comma.ai)。
2. 如果驾驶员摄像头录制已关闭，请在设置中暂时启用驾驶员摄像头录制，直到您复现问题。
3. 使用 comma connect，确定相关片段并上传该片段的日志和驾驶员摄像头视频。
4. 在 Discord 的 `#openpilot-experience` 频道中发布该片段并提供详细描述。

提交反馈前，请确保：

- **openpilot 是最新版本** — 您应使用最新的 openpilot 正式版或 nightly 版
- **驾驶员摄像头能清晰看到驾驶员** — 确保没有遮挡驾驶员视野的物品（如线缆），镜头清洁等
- **设备安装正确** — 设备必须水平居中安装在挡风玻璃上且位置较高

## 其他 Bug

遇到其他问题？在我们的 [GitHub issue 跟踪器](https://github.com/commaai/openpilot/issues/new/choose)上提交 issue。
