# openpilot 是什么？

[openpilot](http://github.com/commaai/openpilot) 是一个开源驾驶辅助系统。目前，openpilot 为日益增长的[支持车型、年款](https://github.com/commaai/openpilot/blob/master/docs/CARS.md)提供自适应巡航控制（ACC）、自动车道居中（ALC）、前向碰撞预警（FCW）和车道偏离预警（LDW）功能。此外，当 openpilot 处于启用状态时，基于摄像头的驾驶员监控（DM）功能会对分心或瞌睡的驾驶员发出警报。了解更多关于[车辆集成](https://github.com/commaai/openpilot/blob/master/docs/INTEGRATION.md)和[使用限制](https://github.com/commaai/openpilot/blob/master/docs/LIMITATIONS.md)的信息。

## 如何使用？

openpilot 专为 comma four 硬件设计使用。

## 工作原理？

简而言之，openpilot 利用车辆现有的 [ADAS](https://en.wikipedia.org/wiki/Advanced_driver-assistance_system) 系统 API，提供比原车系统更出色的加速、制动和转向控制。
