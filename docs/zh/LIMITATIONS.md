# 使用限制

## openpilot ALC 和 LDW 的限制

openpilot ALC 和 openpilot LDW 不会自动驾驶车辆，也不减轻驾驶车辆所需的注意力。驾驶员必须始终保持对方向盘的控制，并随时准备好纠正 openpilot ALC 的操作。

在变道时，openpilot 无法观察侧后方或检查您的盲区。只有在确认安全后，才能轻推方向盘发起变道。

许多因素可能影响 openpilot ALC 和 openpilot LDW 的性能，导致其无法按预期正常工作。这些因素包括但不限于：

* 能见度差（大雨、大雪、大雾等）或干扰传感器运行的天气状况。
* 面向道路的摄像头被泥土、冰雪等遮挡、覆盖或损坏。
* 车辆上过度使用油漆或粘性产品（如车膜、贴纸、橡胶涂层等）造成的遮挡。
* 设备安装不正确。
* 在急弯路段（如匝道、交叉路口等）行驶时；openpilot 被设计为限制其可产生的转向扭矩。
* 遇到受限车道或施工区域时。
* 在高度倾斜的路面上行驶或遇到强侧风时。
* 极热或极冷的温度。
* 强光（来自对向车头灯、直射阳光等）。
* 在丘陵、狭窄或蜿蜒道路上行驶。

以上列表并未穷尽所有可能干扰 openpilot 组件正常工作的情形。驾驶员有责任始终掌控车辆。

## openpilot ACC 和 FCW 的限制

openpilot ACC 和 openpilot FCW 并非允许粗心或分心驾驶的系统。驾驶员仍需密切关注车辆周围环境，并随时准备重新控制油门和刹车。

许多因素可能影响 openpilot ACC 和 openpilot FCW 的性能，导致其无法按预期正常工作。这些因素包括但不限于：

* 能见度差（大雨、大雪、大雾等）或干扰传感器运行的天气状况。
* 面向道路的摄像头或雷达被泥土、冰雪等遮挡、覆盖或损坏。
* 车辆上过度使用油漆或粘性产品（如车膜、贴纸、橡胶涂层等）造成的遮挡。
* 设备安装不正确。
* 接近收费亭、桥梁或大型金属板时。
* 在行车道上有行人、骑行者等道路上行驶时。
* 遇到交通标志或红绿灯时，openpilot 目前不支持识别这些信号。
* 当发布的速度限制低于用户设定的速度时。openpilot 目前不支持检测速度限制。
* 同一车道内有静止车辆时。
* 需要紧急制动时。openpilot 被设计为限制其可产生的减速度和加速度。
* 周围车辆从邻车道近距离切入时。
* 在丘陵、狭窄或蜿蜒道路上行驶。
* 极热或极冷的温度。
* 强光（来自对向车头灯、直射阳光等）。
* 其他产生雷达波的设备造成的干扰。

以上列表并未穷尽所有可能干扰 openpilot 组件正常工作的情形。驾驶员有责任始终掌控车辆。

## openpilot 驾驶员监控（DM）的限制

openpilot 驾驶员监控不应被视为对驾驶员警觉性的精确衡量。

许多因素可能影响 openpilot DM 的性能，导致其无法按预期正常工作。这些因素包括但不限于：

* 低光照条件，例如夜间驾驶或在黑暗隧道中行驶。
* 强光（来自对向车头灯、直射阳光等）。
* 驾驶员面部部分或完全超出驾驶员摄像头的视野范围。
* 驾驶员摄像头被遮挡、覆盖或损坏。

以上列表并未穷尽所有可能干扰 openpilot 组件正常工作的情形。驾驶员不应依赖 openpilot DM 来评估自身的注意力水平。
